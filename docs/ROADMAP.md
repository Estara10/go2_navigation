## 阶段 2：精度与鲁棒性  ⬜

- 标定 `T_base_cam`：平移 + 俯仰/横滚/偏航 + **相机工厂 IMU↔光学外参**；组合到 VINS 用的 IMU 原点。
- **切换 `StaticWalk()` 步态**（`--gait static`，Go2 高层 `SportClient` 已暴露）：已确认 API 存在、默认行为不变、调用失败即退出。**"减小穿插/滑移/运动模糊、利于 VINS 稳定性与停准"是待验证假设**——需现场直线 + 小转弯对比 VINS 稳定性与到点后再决定是否常用。代价是慢；切步态后机器人行为会变，须在安全区、遥控在手验证。
- VINS 转弯/低纹理稳定性：好纹理视野、转弯速度限制、健康检测反馈。

## 阶段 4：室外长时间跟踪（不回到原点）  ⬜ ❓

- 场景：**室外、长时间、不回到原点**（无重访）。
- 结论：VIO 是相对定位，会随时间/距离漂；**无重访 → 闭环/pose-graph 回环用不上**。必须依赖**绝对基准 + 多传感器融合**：
  - **主选：GNSS-RTK**（cm 级绝对位置），与 IMU + VIO/LIO + 腿部里程计做 EKF/ESKF 融合。
  - **抗遮挡/拒止：LiDAR-Inertial Odometry（LIO，如 FAST-LIO2 / LIO-SAM）** 作局部里程计，GPS 降级时兜底。
  - **腿部里程计**：Go2 足端接触 + 腿运动学，视觉/GPS 都失效时兜底，也作一致性校验的独立速度源。
  - 可选 UWB（有信标布设时）。
- 不用于精密定位：Go2 自带相机只作粗定位/避障。
- 待定：场地范围、精度要求、GPS 可用性/多路径、是否允许布设 RTK/UWB 基站、Orin 算力是否够 LIO+VIO 并跑。
