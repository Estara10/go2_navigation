# 现场终端（完整 4 个，按顺序启动）

启动顺序：A 相机(Orin) → C VINS(电脑) → D 桥接(电脑) → B 原生工具(电脑)。
收尾逆序：先停原生工具 → 桥接 → VINS → 相机，逐个核对残留进程。

以下 IP、ROS domain、SDK/VINS 路径都是历史现场值，执行前由操作者显式确认，不照抄默认。

## 终端 C：VINS（电脑，独立终端）

前置：VINS 必须已按 scripts/go2_vins/README.md 构建到项目内 install 目录。
当前本机未构建（见文末「当前缺口」）；先构建再照下面启动。

先复制配置到本轮目录并改写 output_path / pose_graph_save_path（相对启动目录）：

RUN=/home/lidio/go2_navigation/logs/field_vins/$(date -u +%Y%m%d_%H%M%S)
mkdir -p "$RUN/config"; echo "RUN=$RUN"
cp scripts/go2_vins/config/d435i_480x270/*.yaml "$RUN/config/"
# 编辑 "$RUN/config/realsense_stereo_imu.yaml" 里的 output_path、pose_graph_save_path 指向 $RUN

source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=42
export ROS_LOCALHOST_ONLY=0
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><NetworkInterfaceAddress>192.168.123.99</NetworkInterfaceAddress></General></Domain></CycloneDDS>'
export VINS_IMAGE_QOS=best_effort
export VINS_SYNC_DIAGNOSTICS=1
source /home/lidio/go2_navigation/install/vins/setup.bash

ros2 run vins vins_node "$RUN/config/realsense_stereo_imu.yaml"
# config_file 是位置参数（fork 源码 non_ros_args[1]，已核对），不是 -p 参数。

确认日志出现 Initialization finish! 且 /odometry 有输出后，再开桥接。
未初始化时先停，不要移动机器人。

## 终端 D：桥接（电脑，独立终端）

先 conda deactivate（或用干净 Humble shell），否则 Anaconda libstdc++ 缺 GLIBCXX_3.4.30 会跑不起来。

source /opt/ros/humble/setup.bash
export ROS_DOMAIN_ID=42
export ROS_LOCALHOST_ONLY=0
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><NetworkInterfaceAddress>192.168.123.99</NetworkInterfaceAddress></General></Domain></CycloneDDS>'

cd /home/lidio/go2_navigation
./build/go2_vins_bridge/go2_vins_bridge \
  --config scripts/go2_nav_plan/config/d435i_provisional.conf \
  --vins-topic /odometry \
  --control-port 46001 --state-port 46002
# 启动前确认二进制是最近一次构建的（build/go2_vins_bridge/ 与 build/final_bridge/ 都有同名文件）。

## 终端 B：原生工具（电脑，你发运动命令）

第一次：负向检查，不运动

cd /home/lidio/go2_navigation
export UNITREE_SDK2_ROOT=/home/lidio/Libraries/unitree_sdk2
RUN=/home/lidio/go2_navigation/logs/field_runs/$(date -u +%Y%m%d_%H%M%S)_check
mkdir -p "$RUN"; echo "RUN=$RUN"

env LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu:"$UNITREE_SDK2_ROOT/lib" \
  ./build/final_sdk/go2_native_motion \
  --domain 0 --interface enp7s0 \
  --control-source vins \
  --vins-control-port 46001 --vins-state-port 46002 \
  --vins-timeout-s 0.5 \
  --csv "$RUN/native_motion.csv"

输入 origin；应看到 unmeasured_extrinsic 拒绝。然后 quit。

第二次：机制测试

同一个终端重新启动：

env LD_LIBRARY_PATH=/usr/lib/x86_64-linux-gnu:"$UNITREE_SDK2_ROOT/lib" \
  ./build/final_sdk/go2_native_motion \
  --domain 0 --interface enp7s0 \
  --control-source vins \
  --allow-unmeasured-extrinsic \
  --vins-control-port 46001 --vins-state-port 46002 \
  --vins-timeout-s 0.5 \
  --csv "$RUN/native_motion.csv"

按顺序输入：

origin
status
plan 0.5 0

停稳并测量后：

stop

再做下一轮就重新放回 A、重新对齐，重新 origin/status/plan。每轮测量按
docs/FIELD_RUN_MEASUREMENT.md：量前向 L_fwd、横向 L_lat，当场写记录卡。
